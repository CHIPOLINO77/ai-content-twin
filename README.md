# AI Content Twin

Браузерный MVP AI Content Twin для создания идей, хуков, сценариев и монтажных планов через Polza AI.

## Что реально работает сейчас

- GitHub Pages + собственный домен `korzh-fan.fun`;
- API-ключ хранится только в `localStorage` браузера;
- Content Profile строится по вставленной расшифровке/тексту автора;
- Idea Lab генерирует идеи в JSON и показывает их в интерфейсе;
- Content Generator создаёт произвольный контент по профилю;
- Shorts Studio создаёт структурированный план вертикального ролика: hook, script, beats, visual, captions, монтаж, CTA и hashtags;
- Shorts Studio умеет запускать реальную генерацию AI-видео через Polza Media API с `kling/v3` (Kling 3.0), включая вертикальный формат 9:16, нативный звук и асинхронный статус задачи;
- выбранные видео сохраняются только как локальная библиотека браузера — серверной загрузки и транскрибации видео в этой версии нет.

## Архитектура

`korzh-fan.fun → GitHub Pages → Polza AI API (chat + media)`

Используется OpenAI-совместимый Chat Completions API Polza. Текущая версия интерфейса использует модель `openai/gpt-6-astra`.

## Важно про API-ключ

Ключ не хранится в GitHub, но при прямом вызове API из браузера он всё равно доступен текущему браузеру и сетевым инструментам пользователя. Для публичного многопользовательского сервиса безопаснее вынести Polza API за собственный backend/proxy.

## Следующий технический уровень

Видео → локальная/серверная транскрибация → анализ речи и структуры → Content Profile → идеи → сценарий → Shorts Studio → Polza AI Video → готовый вертикальный клип.

### AI Video

Текущая интеграция использует `POST /api/v1/media` и `GET /api/v1/media/{id}` Polza. В интерфейсе выбран `kling/v3` — Kling 3.0; параметры: 9:16, 5/10/15 секунд, режим `std`, звук включён. Polza указывает для Kling 3.0 длительность до 15 секунд и нативный звук. Генерация асинхронная: интерфейс опрашивает статус и показывает готовое видео, когда API возвращает URL результата.
